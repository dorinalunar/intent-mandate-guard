## Summary

```text
IntentMandateGuard v3.0 is a semantic execution authorization guard on GenLayer. Principals register bounded mandates (rules, allowed methods, quota_cap, tx_cap, ttl), operators request single-use execution tickets audited by validator LLMs with verbatim quote grounding, executors redeem tickets against exact cryptographic intent anchors, and execution receipts record downstream calldata hashes on-chain.
```
